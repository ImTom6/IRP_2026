
**Copy Number Full Pipelines:** Provides full pipelines for 50kb, 100kb, and 500kb window sizes
**Copy Number Steps:** Provides individual steps for copy number pipeline (Using 50kb window size as an example)
**50kb_to_100kb.py:** Used to convert IchorCNA provided 50kb .wig files into 100kb .wig files, could be adapted to work with different window sizes
This research used the ALICE High Performance Computing facility at the University of Leicester.
